Values are volts vs SHE at 25 °C, from the source named under each electrode: Silvion data sheet "Potential relationships for several different reference electrodes", Park (Materials Performance, September 2009), ISO 12696:2022 Table D.2, EN 12473:2005 and EN 12499:2003. ISO 12696 gives only differences between electrodes, so values marked "Derived from ISO 12696" assume Ag/AgCl (sat. KCl) = 0.199 V. Seawater, fresh water and zinc values are approximate: EN 12473 allows about ±30 mV for Zn/seawater, and Ag/AgCl in dilute chloride shifts about 60 mV per tenfold change in chloride (EN 12499). RHE uses E(RHE) = E(SHE) + 0.0592 × pH. Real electrodes vary with filling solution, age and temperature, so check your electrode's datasheet when accuracy matters.
